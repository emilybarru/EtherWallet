# EtherWallet

Syncs encrypted cryptocurrency transactions and wallet balances across multiple devices in real-time securely.

The key benefits of using EtherWallet include:

- Syncs encrypted cryptocurrency transactions and
- wallet balances across multiple devices
- in real-time securely

## Key Features

- Syncs encrypted cryptocurrency transactions and
- wallet balances across multiple devices
- in real-time securely

## Technology Stack

- typescript
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/EtherWallet.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure EtherWallet, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
